Matter Tag Provider

This module connects to a python-matter-server instance and exposes Matter smart home device data as Ignition tags.

Configuration

In the Ignition Gateway web UI, create a new tag provider of type Matter Server under the Tags configuration page. Set:

  • Server URL — WebSocket URL of the python-matter-server (e.g. ws://192.168.1.100:5580/ws, default ws://localhost:5580/ws).

Tag Tree

Tags are exposed under the provider as:

Nodes/Node {id}/Attributes/{Endpoint}/{Cluster}/{Attribute}

Server metadata (connection status, fabric ID, SDK version, schema version) is available under Server/.
